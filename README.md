# ₸ Тенге Трекер — личный финансовый трекер

Mobile-first финтех-dashboard: доходы, расходы, накопления, цели, депозит. Светлая/тёмная тема, нижняя навигация, кнопка «+ поездка» (120 ₸).

## Запуск (MVP)

Без сборки — просто откройте файл:

```
index.html
```

или поднимите локальный сервер (чтобы работал fetch к Google):

```powershell
# вариант 1: python
python -m http.server 8000
# открыть http://localhost:8000

# вариант 2: node
npx serve .
```

Все кнопки рабочие уже сейчас — данные хранятся в `LocalStorage`.

## Структура

```
index.html                  # SPA-каркас (Главная / История / Аналитика / Цели)
css/styles.css              # mobile-first стили + тёмная тема
js/config.js                # URL Apps Script, тариф транспорта, категории
js/finance.js               # все формулы (чистые функции, без DOM)
js/store.js                 # LocalStorage + синхронизация с Google Sheets
js/ui.js                    # отрисовка страниц
js/app.js                   # роутинг, модалки, обработчики
google-apps-script/Code.gs  # backend для Google Sheets
SETUP_GOOGLE_SHEETS.md      # инструкция подключения таблицы
```

## Формулы

- Чистый доход = Доходы − Расходы
- Доступные деньги = Доходы − Расходы − Накопления
- Общий капитал = Доступные + Накопления (= Доходы − Расходы)
- Перевод в накопления/на депозит **не уменьшает** общий капитал — только перемещает деньги.
- Пополнение депозита автоматически создаёт операцию типа «Накопление».

## Google Sheets

См. `SETUP_GOOGLE_SHEETS.md`. Коротко: вставить `Code.gs` в Расширения → Apps Script,
развернуть как веб-приложение с доступом «Все», URL вставить в `js/config.js` → `GOOGLE_SCRIPT_URL`.

## Что дальше (расширение)

- Авторизация (Firebase Auth / Google OAuth) + поле `UserID` в листах.
- Несколько счетов/карт: новый лист `Accounts`, поле `AccountID` в Transactions.
- Автоимпорт: CSV-загрузка выписок + разбор.
- PWA: добавить `manifest.json` + service worker для установки на телефон.
- Графики: заменить CSS-бары на Chart.js при желании.
