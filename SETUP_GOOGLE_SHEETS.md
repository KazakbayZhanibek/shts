# Подключение Google Sheets (5–10 минут)

Сайт уже полностью работает локально (LocalStorage). Чтобы данные хранились в Google-таблице и были доступны с телефона и компьютера — выполните шаги ниже.

## 1. Создайте таблицу

1. Откройте https://sheets.new — создастся пустая таблица.
2. Переименуйте её, например, «Финансы».
3. Ничего вручную создавать не нужно — скрипт сам создаст листы `Transactions`, `Goals`, `Deposits` с шапками:
   - Transactions: `ID | Date | Type | Amount | Category | Description | CreatedAt`
   - Goals: `ID | Name | TargetAmount | CurrentAmount | Deadline | CreatedAt`
   - Deposits: `ID | Name | Balance | InterestRate | StartDate | Term | CreatedAt`

## 2. Вставьте backend-скрипт

1. В таблице: **Расширения → Apps Script**.
2. Удалите содержимое `Code.gs`, вставьте код из файла `google-apps-script/Code.gs` этого проекта.
3. Сохраните (Ctrl+S).

## 3. Опубликуйте как веб-приложение

1. В Apps Script: **Развернуть → Новое развертывание**.
2. Тип: **Веб-приложение**.
3. Параметры:
   - Выполнять как: **Я (ваш аккаунт)**
   - Доступ: **Все пользователи** (иначе сайт не сможет читать без логина)
4. Нажмите **Развернуть**, разрешите доступ.
5. Скопируйте URL вида `https://script.google.com/macros/s/AKfyc.../exec`.

## 4. Подключите сайт

1. Откройте `js/config.js`.
2. Вставьте URL:
   ```js
   GOOGLE_SCRIPT_URL: "https://script.google.com/macros/s/ВАШ_ID/exec",
   ```
3. Обновите сайт. Индикатор вверху сменится с «● локально» на «● sheets ✓».

## Как это работает

- При загрузке сайт делает `GET ?action=list` и забирает все 3 листа.
- При каждом добавлении/редактировании/удалении сайт:
  1. сразу сохраняет в LocalStorage (мгновенно, работает офлайн),
  2. фоном отправляет `POST {action:"upsert"/"delete", sheet, row}` в Apps Script.
- Все суммы — числа (без символа ₸), даты — `ГГГГ-ММ-ДД`.

## Проверка

1. Добавьте доход на сайте → строка должна появиться в листе `Transactions`.
2. Обновите страницу → данные подтянутся из таблицы.
3. Откройте сайт с телефона → те же цифры.

## Частые проблемы

- **CORS / не грузится**: убедитесь, что доступ «Все пользователи», а запрос идёт POST с `Content-Type: text/plain` (так уже в `store.js`).
- **Пустая таблица после деплоя**: добавьте первую запись на сайте — листы создадутся сами.
- **Хочу с нуля**: очистите LocalStorage в DevTools → Application → Local Storage.
